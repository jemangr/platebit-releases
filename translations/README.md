# Platebit translations

These are the texts of the Platebit app in Italian, Spanish, French, German and Portuguese (Portugal). Each file maps the English text to its translation:

```json
"Log a sport": "Registra uno sport"
```

| File | Language |
|---|---|
| `it.json` | Italiano |
| `es.json` | Español (España) |
| `fr.json` | Français |
| `de.json` | Deutsch |
| `pt.json` | Português (Portugal) |

The translations are new. If something reads wrong or odd, tell us:

- **In the app:** Settings → *Suggest a better translation*.
- **Here:** open an issue with the *Translation fix* form, and write where you saw the text, what it says and what it should say.

A few things stay as they are on purpose:
- Gym exercise names (Bench press, Deadlift, Upper A…) stay in English in every language.
- Platebit, Pro AI Cloud, Health Connect, Wear OS, Hevy and the units (kcal, g, kg, ml) aren't translated.
- `%s` and `%d` are filled in by the app (a number, a name, a time). Keep them, as many as the English has.

These files are updated with every version of the app. The app itself isn't open source; only its texts are published here.
